# 実機での受け入れ確認

## 自動テスト範囲

日時表記、同秒UUID分離、スナップショット不変性、項目差分、複製ID、履歴画像参照、安全URL、未知schema拒否、インポートID変換、IndexedDBへの原子的保存、古いrevisionの拒否、復元直前の保持、不正インポート無変更、画像不足時書出し停止、JSON往復、検証失敗の無変更、改ページ、作者メモ除外、出力種類・ロゴ制御、ページ上限。

Canvas改ページテストは描画APIのモックを使うロジック検証です。見た目や実ブラウザ描画の保証ではありません。

## iPhone / iPad / PC（公開後）

- 初回案内を最後まで進む／スキップする。再起動で勝手に再表示されず、設定から再表示できる。
- 世界と5種類の項目を作成。日本語長文・改行・絵文字を保存し、再読み込みして保持される。
- 写真を登録。縦横の向き、表紙変更、4枚上限、非対応形式の案内を確認。
- v1.21を記録→項目と画像を変更→差分→旧版閲覧→復元。復元前の状態が履歴に残る。
- JSONをファイルアプリに保存→別ブラウザへ読込。世界・項目・画像・メモ・履歴が揃う。
- 同じIDを置換した場合、置換前の世界が安全コピーで残る。
- 全世界のごみ箱移動後でも設定から元へ戻せる。
- 文字を特大／UIをゆったり／ブラウザ文字を200%にしても主要操作が切れない。
- 2タブで同じ世界を編集。古いタブが保存を拒否され、入力をコピーできる。
- PNG単ページ・複数ページZIP・PDFを保存し、日本語・画像・最終行・改ページを実際に確認。
- 作者用メモがPNG/PDFに出ず、JSONには残る。
- オフライン準備完了後にSafariからホーム画面へ追加。機内モードで再起動・編集・履歴・JSON・PDFを使う。
- アプリ更新案内では編集中に強制リロードされず、保存して閉じた後に更新できる。

## 既知の制限

保存領域はブラウザ／URLに紐づく。OSやSafariで保存領域保護を拒否される場合がある。
画像PDFは検索・文字選択不可。24ページ上限。画像原本は別保管。
フォント収録外の字・絵文字は端末フォールバックになる。最終的なiOSレイアウトは実機で確認する。
