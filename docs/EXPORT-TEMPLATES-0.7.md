# Preview 0.7 — 改ページとEntityテンプレート

## パンフレットの項目分割

- `自動`：Preview 0.5までの連続配置。ページ末尾の残りが少ない場合だけ改ページする。
- `1項目1ページ優先`：現在ページへ通常配置、次に行間・余白・画像を軽く詰めた配置を試す。なお収まらず、次ページへ流れる量が本文領域の50%以上なら次ページ先頭から開始する。
- `しきい値ベース改ページ`：次ページへ流れる量が本文領域の33%・50%・66%以上になる場合、項目を次ページ先頭から開始する。
- `常に1項目ごと改ページ`：各Entityを必ず新しいページから開始する。

文字サイズは縮小しない。画像は縦横比を維持する。1ページを超える長い項目は通常サイズのまま複数ページへ分割する。従来の`separate`オプションを渡すコードも互換動作する。

## Entity項目テンプレート

キャラクター、場所、組織、設定・記事、作品、用語辞典の全Entity種別に内蔵テンプレートを用意する。テンプレートはカスタム項目名だけを追加し、Entity固有の入力内容は保持する。

反映方法は次の2つ。

- `現在の項目へ追加`：入力済みカスタム項目を残して末尾へ追加する。
- `カスタム項目を置き換え`：確認後、入力済みカスタム項目をテンプレートの項目へ置き換える。

自作テンプレートは設定画面から作成・編集・並べ替え・削除でき、端末内の全世界で共有する。削除しても、すでにEntityへ反映した項目と内容は削除しない。

## 保存と互換性

- 状態とバックアップのschemaVersionは3。
- schemaVersion 1/2は、自作テンプレート0件として読み込む。
- 自作テンプレートは全世界／個別世界のJSONバックアップ双方へ含める。
- 読み込み先に同一IDまたは同種別・同名の別内容テンプレートがある場合、既存を上書きせず「（読み込み）」付きの安全コピーとして追加する。
- 未知の将来schemaVersionは拒否する。
