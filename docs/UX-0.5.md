# Preview 0.5 — 項目から別の姿を扱う

基準：W-Pam-Preview-0.4-Dimensions-Source.zip。基本方針0.5に沿うローカルUX改善。

## 使い方

1. キャラクター・場所などの詳細を開く。名前の下に現在のDimensionを表示。
2. 「このDimensionで編集」でこの項目を直接編集。同じ条件の差分がある場合は自動で開く。
3. 変更するフィールドだけチェック。未チェックは継承、チェックした空欄は明示的な空欄（必須名称などの検証は維持）。入力の初期値には現在の条件での解決済み値を使う。
4. 保存前に基本値と保存後のこの条件を比較できる。画像・ID・関連先は共通土台のまま。
5. 「この条件の掲載指定」は掲載・非掲載・継承の3択。非掲載にした項目につながる関係も通常表示から除外。
6. 非掲載になっても詳細は作者用として開いたまま。再訪時はパンフレット上部「非掲載の項目を探す」から開く。
7. 「別の条件で見る」で項目を開いたまま条件を切り替える。世界全体の表示条件も追従する。
8. 登録済み差分の「移動／複製」から適用先を変更。基本項目を別IDで作り直す操作ではない。
9. 項目内の関係管理、または関係ビューから関係の差分編集へ進める。非掲載の関係は項目内または世界全体の対象選択から探せる。

## 移動・複製の意味

- 複製：選んだ差分の条件と値を新しい条件へコピー。元は残す。
- 移動：選んだ差分のみ条件を変更。差分IDと適用順を維持する。
- 移動元を非掲載にする：任意。元の条件にvisible:falseを残す。未選択なら基本・他の姿を継承する。
- 差分のvisible値はそのまま移動・複製する。移動先で必ず掲載になる操作ではない。
- 空条件・同じ移動先・既存の同条件差分がある先への操作は拒否。無断上書きしない。
- 他の組合せ差分は変更しない。より具体的な条件の差分が掲載指定やテキストを上書きすることはある。
- 「この条件だけに存在する」排他的所属や全軸の組合せ一括移動は追加していない。
- 掲載先だけを整理したい場合は、各条件の掲載指定を使う。単独の一括移動モードにはしていない。

## 安全と互換性

- 通常編集は「基本データを編集」と明記。項目削除は全Dimensionへの影響を確認する。
- 差分保存・削除・移動・複製・掲載変更の直前に世界のSnapshotを保存。同じIndexedDBトランザクションで保存され、失敗時は一部だけ変更しない。
- 「履歴・差分を見る」から安全記録を復元できる。復元は項目だけでなく世界全体が対象。
- Snapshot上限は従来の1000件。自動記録により保存量は増えるため、定期的にJSONバックアップを保管する。
- バックアップから別世界として追加する場合も、ごみ箱にあった世界はごみ箱内へ復元する。
- 同じIDはバックアップ側で上書きできる。置換前の状態は別IDの安全コピーとしてごみ箱へ残す。
- ごみ箱では本棚への復元に加え、確認後の完全削除ができる。完全削除時は他の世界・履歴から参照されない画像も整理する。
- schemaVersionは2を維持。ID・画像・関係・Snapshot・フォルダ定義の形式は変更なし。旧v1/v2読込を維持。
- 非掲載は公開アクセス制御ではない。本文中に手入力した名前・説明は自動で伏字にしない。
- 未保存の差分入力にはページ離脱警告と、閉じる・条件変更・対象変更時の確認を追加。
- ブラウザ実機・iPhone/PWA更新操作は未検証。既存デザインを維持して狭幅の折返しと44pxの操作領域を追加。

## 検証

既存48件に移動・複製・競合拒否・履歴保全・関係追従・UI初期描画のテストを追加。
`npm test` と `npm run build` で確認する。詳細なタップ操作を含むE2Eテストではない。

## 納品

- Source ZIP：ソース一式。node_modules/distは含めない。
- Deploy ZIP：distの中身のみ。ZIP直下にindex.html。従来と同じNetlifyサイトへ手動デプロイ。
- 更新前のJSONバックアップを端末外に保存してから差し替える。
