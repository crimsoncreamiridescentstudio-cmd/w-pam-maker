# W-Pam Preview 0.4 — 世界フォルダとDimension

基準: W-Pam-Preview-0.3-UISettingsFix-Source.zip（未改変ZIPから展開して改修）

## 使い方

1. 「世界の本棚」の「世界フォルダ → 新規作成」で名前と説明を入力。
2. 「軸を追加」で「世界線」「ネタバレ」「時系列」「章」などを作成し、それぞれの選択肢を入力して保存。
3. パンフレットを開き、上部の「所属する世界フォルダ」で所属先を選ぶ。
4. Dimension欄で各軸を独立して選択。指定しない軸は条件に含めない。「基本データに戻す」ですべて解除。
5. 「このDimensionの差分を編集」から対象を選択。非掲載の項目や関係も選択可能。
6. 条件を調整し、変更するフィールドだけチェックして入力・保存。未チェックのフィールドは継承。空文字を入力すると、その条件で空欄になる。
7. 登録済み差分は編集・削除可能。同一条件の差分がある場合は既存差分を開いて編集。
8. 表示、検索、関連項目、関係・相関図、PNG/PDF出力に現在の選択を反映。

通常の「編集」は常に基本データを編集する。選択中のDimensionがあっても差分を基本値へ書き戻さない。差分表示中は関係・年表・グループの通常編集を読み取り専用にし、「基本データに戻す」で編集できる。

## 差分の仕様

- パンフレット・キャラクター・場所・組織・設定記事・作品・用語のテキスト項目と追加項目に対応。
- EntityとRelationは掲載／非掲載に対応。通常は掲載。非掲載のEntityにつながるRelationも表示対象から除外。
- Relationの差分対象は関係名・方向・補足メモ・掲載。from/toは差分で変更できない。
- 画像・画像表示位置・関連先・親子関係・お気に入り・ピン留めは基本データで管理。
- 追加項目は配列全体を差し替える。
- 一致した差分を条件数の昇順で適用し、条件数の多い差分を優先。
- 条件数が同じ場合は配列順（新規登録順）で後のものを優先。編集で順番は変わらない。競合しうる入力には案内を表示。優先順位番号の入力は不要。
- 同一条件セットは1件まで。同じ軸を1つの差分の中で複数指定することも禁止。
- Dimension選択は閲覧中の状態。パンフレットを開き直すと基本データに戻る。
- タグ、グループ、年表は従来の分類として維持。グループ・年表から非掲載項目へのリンクは表示時に除外するが、グループや出来事の本文自体はDimension差分対象ではない。
- 非掲載は表示切替でありアクセス制限ではない。基本データや作者用のバックアップには全差分が入る。

## フォルダと履歴の保全

- 軸／選択肢は、現在のデータ・履歴・ごみ箱で使用中なら削除不可。使用差分件数を表示。
- 名前変更はIDを維持するため既存差分に影響しない。
- フォルダを削除すると所属パンフレットは未所属に戻り、本体・差分・履歴を保持。
- 差分があるパンフレットには削除時のフォルダ定義を `dimensionArchive` として退避。未所属では差分を適用せず基本データを表示する。
- パンフレット上部の「元のフォルダを復元」で退避定義を復元して再所属できる。同じIDが既存なら別IDの復元フォルダを作成し、既存フォルダは上書きしない。
- 差分・履歴の軸IDを持たないフォルダへの移動は拒否。単なる名前の一致を同一軸とは見なさない。
- Snapshotは従来どおりContentを保存。フォルダ定義は現在の共有設定を参照する。
- 既存パンフレットの複製・安全コピーは所属と差分を維持。

## 保存・互換性

- Stateと新バックアップはschemaVersion 2。
- schemaVersion 1の保存データとバックアップを読込可能。旧パンフレットは未所属・差分なしのまま移行。
- IndexedDBのデータベース名 `w-pam` とオブジェクトストアは変更しない。読込で移行し、次回保存でv2を永続化。
- 未知の将来バージョンは拒否。
- 全体バックアップは世界フォルダ定義、差分、Snapshot、画像、退避定義を含む。従来のUI設定バックアップ仕様は変更しない。
- 同じIDで内容が異なるフォルダをインポートすると別のフォルダを作る。既存パンフレットの共有定義を上書きしない。
- 画像の参照・再採番・保存方式は従来どおり。差分に画像IDを持たせない。
- 更新前の旧形式バックアップを保管すること。新形式を旧アプリへ戻す読込互換は対象外。

## 実装箇所

- `src/model.ts`: 型・Zodスキーマ・差分・Snapshot比較・複製。
- `src/dimensions.ts`: 移行、選択検証、差分解決、削除・所属変更、使用数、整合性検証、フォルダインポート。
- `src/dimension-ui.tsx`: フォルダ管理、所属、軸選択、差分編集。
- `src/db.ts`: v1/v2読込・保存・バックアップ・差分の整合性確認。
- `src/main.tsx`: 表示直前のContent解決、基本編集の分離、画像/PDF出力接続。
- `src/workspace.tsx`: 非掲載になった相関図中心の選択を全体表示へフォールバック。既存Zoom/Pan/Fit/100%中央・ラベル描画を維持。
