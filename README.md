# w-pam-maker

創作世界をパンフレットのように作成・整理できるローカル保存型Webアプリ / PWA
まずはローカルでも使えるようにしたいネ！

## Preview 0.3

白紙からつくる創作世界観光パンフ。React / TypeScript / Vite、IndexedDBのみ。Googleログイン、Firebase、SNS、クラウド同期は使用しません。

### 起動・公開

Node.js 22.12以降（開発検証は24）で `npm ci` → `npm run dev`。
`npm test` で自動テスト、`npm run build` で本番ビルド。静的配信対象は `dist` です。
Netlifyでこのリポジトリを選び、ブランチ main、ビルドコマンド `npm run build`、公開ディレクトリ `dist`。環境変数・APIキー不要。
PWAはHTTPSまたはlocalhostで動作します。HTMLファイルを直接ダブルクリックする起動方法には対応しません。

### できること

- 複数Worldの作成・編集・閲覧・複製・ごみ箱移動／復元
- キャラクター、場所、組織、設定・記事、作品、用語辞典の登録と編集、正式名称／表示名・通称、削除前の安全記録
- 独立データとしての関係性（起点・相手・関係名・方向・補足）と、種類／中心項目で絞れる自動相関図
- グループ／コレクション、出来事と関連項目を結ぶ年表、場所・組織等の親子階層
- 名前・本文・種類・タグ・所属・地域の複合検索、お気に入り、ピン留め、最近の編集、ランダム散策
- 自由なカスタム項目、全Entity入力テンプレート、自作テンプレート、セリフ・口調サンプル
- 各項目に最大4画像、表紙選択、表示位置調整、リサイズ、高精細サムネイル、Blob保存
- 項目同士の関連設定と、`[[項目名]]`／`[[項目名|表示文字]]`によるタップ式の概要参照
- 世界全体のスナップショット、日時番号 YYYYMMDD-HHmmss、自由なバージョン名・タイトル・メモ
- 任意の2地点／現在の編集内容との項目単位差分、過去版閲覧、復元前の安全記録
- JSONバックアップ（1世界／全世界、履歴・画像・作者用メモ込み）と検証付きインポート
- インポートはIDを振り直した追加が標準。同じIDの置換時は既存世界を安全コピーとして残す
- 世界全体／個別項目のPNG・PDF書き出し、4出力テンプレート、出力項目の個別選択、種類選択、4種の改ページ方式、ロゴ、解像度、ページプレビュー
- 文字サイズ、余白密度、ライト／ダーク／端末外観、設定のIndexedDB保存
- 初回チュートリアル（スキップ可）、設定とヘルプからの再表示
- 検索・分類絞り込み付きの「Tips・使い方」（Dimension、関係、保存、バックアップ、書き出し等）
- フォント・アイコンを含むオフラインPWA、手動更新の案内、ホーム画面アイコン
- 共通OGP画像 `public/og.png`。Netlifyビルド時の標準URL環境変数から絶対画像URLを設定（ローカルビルドでは画像メタタグを省略）

### 保存と限界

「保存する」は作業内容の保存。「ここまでを記録」は編集とは独立した節目の固定です。文字入力ごとの自動保存ではありません。
同一ブラウザでも別タブが先に更新した場合は上書きを拒否します。編集中の文章をコピーし、編集を閉じて最新状態を読み直してください。

IndexedDBは原本の唯一の保管場所にしないでください。サイトデータ削除・端末故障・容量回収で失われる可能性があります。URLのドメイン変更やブラウザ変更時はJSONで移してください。GitHubに利用者の世界データは保存されません。

プレビューの保護上限：世界100件（安全コピー・ごみ箱含む）、1世界10,000項目／1,000履歴／50,000関係／10,000出来事／5,000グループ、項目名100文字、文章欄50,000文字。検索は200件、相関図は80関係・40項目、年表は300件を一度に表示します。画像は入力20MB／50MPまで・本体は長辺1600px、サムネイルは長辺960pxへ縮小、4枚まで。HEICはJPEGなどへ変換してください。GIF等は静止画として扱います。旧版の320pxサムネイルは表示時に端末内で順次作り直します。
JSON読込・書出しは100MBまで。大きい場合は世界ごとに分割。履歴の画像を壊さないため、外した画像は自動削除しません（容量の回収機能は将来対象）。

PNGは複数ページの場合ZIP。PDFはA4縦の画像PDFで、文字検索・選択・読み上げ用タグはありません。1回24ページまで。原稿は切り捨てず、超過時は処理を中断します。表示サイズ設定と出力の文字サイズは独立しています。
画像・PDFには作者用メモを含めません。JSONには含みます。JSONは自分の保管用を基本としてください。

ネット接続が必要なのは初回のアプリ取得と更新です。初回キャッシュには日本語フォントも含むため通信量があります。オフライン準備完了の表示後に機内モードで確認してください。
